## 7 不照抄原实现的 4 处（设计文档自陈的实现/文档不一致）

原作者文档列出其实现里 4 处问题。本机重写时按下面的口径**从设计上避免**，而不是先复现再修：

1. `tiers[].boss_affix_pool`：字段若存在就必须真正生效——把命中的 `Tier` 传进 `spawnOne()`，池的优先级 `tier > scaling > 全量` 一处算清。
2. 「BOSS 层取 `mobs[0]`」：不附加「且配了 `boss_affix_pool`」这个隐藏前提，BOSS 层就是取 `mobs[0]`。
3. 生成上限：`max_spawns_per_wave` / `max_alive_mobs` 语义要在注释与文档里写明是「丢弃」还是「推迟」，配置注释与实际行为必须一致（原实现注释说推迟、代码是丢弃）。
4. `multiply_total`：不用 `addTransientModifier`（`AttributeInstance.save()` 只写 permanent modifiers，区块重载后加成会丢），改用 `addPermanentModifier` 或实体加载时重跑词条；`immune_to` / `melee_damage_type` 继续走 `getPersistentData()`（会随实体存档）。

## 8 环境与构建坑（本机既有经验，写在这防止重复踩）

- **中文路径**：项目在 `Documents\开发\...` 下。编译打包与 `run*` 实测不受影响，但 Gradle 的 `Test` 任务会因非 ASCII 路径加载不了测试类
  → 自动化校验一律用 `JavaExec` 自建任务（R6 就是这个模式），**不要引入 `src/test/java` + `Test`**。
- **`gradle.properties` 按 ISO-8859-1 读取**：里面写中文会在生成的 `mods.toml` 里变 mojibake。已验证：元数据全 ASCII，中文名走 lang 文件。
- **产物只用 `build/libs/`**（已 SRG 重混淆）；`build/devlibs/` 是开发版，不要发布。
- **长构建不要接 `head`/`tail`**：SIGPIPE 截断后退出码仍是 0。落盘日志再 grep，并核对阶段标记（如 `BUILD SUCCESSFUL`、`All 0 required tests passed`）是否出现。
- **`run*` 之后若报文件被锁**：`./gradlew --stop` 关掉残留 daemon 子 JVM 再重跑。
- **`.github/workflows/build.yml` 是 MDK 原样**（ubuntu runner + `./gradlew`），Windows 打的 zip 不带可执行位，真接 CI 时要补 `chmod +x gradlew`。当前没接任何远端。
